Decision 02

Deterministic — not AI-first.

“The most dangerous thing you can add to a governance tool is uncertainty. The same file should always produce the same score.”

Every design tool today reaches for an LLM. But a governance metric that changes without the file changing isn’t a metric — it’s a guess. So the measurement core stays deterministic. That single constraint earns four properties for free:

What each approach costs a governance score
Property If the core were AI-first Deterministic core — chosen
Reproducible If AI-firstTwo runs on the same file can return two scores. Deterministic — chosenSame file, same score — every run, every machine.
Private If AI-firstProprietary files are sent to a model provider to be read. Deterministic — chosenRules run in Figma’s sandbox; design data never leaves your machine.
Offline If AI-firstNo connection, no score. Deterministic — chosenNo API or model endpoint — it works wherever Figma works.
Fast If AI-firstEvery scan waits on an inference round-trip. Deterministic — chosenA scan waits on nothing — rules run locally on the layer tree.

AI still has a place — after the score, not inside it. The engine doesn’t guess. The next version will explain.
