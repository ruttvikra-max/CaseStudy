Decision 02

Deterministic — not AI-first.

“The most dangerous thing you can add to a governance tool is uncertainty. The same file should always produce the same score.”

Every design tool today reaches for an LLM. But a governance metric that changes without the file changing isn’t a metric — it’s a guess. So the measurement core stays deterministic, and AI is only allowed in after the score exists.

Deterministic coreProduces the score

  1. 01Ingest

    Connect to a Figma file and its linked design system — the source of truth.

  2. 02Scan

    Traverse the component tree, token usage and naming across every layer.

  3. 03Detect

    Flag detached instances, token drift, overrides and naming violations.

  4. 04Report

    Output the UI blueprint and compliance score — analysis only.

AI enters here

AI layer · next version

Explain

Reads the finished report and explains it. It never changes the score.

Keeping AI out of the core earns four properties for free:

  • Reproducible

    Same file, same score — every run, every machine.

  • Private

    Design data never leaves your machine.

  • Offline

    No API or model endpoint to reach.

  • Fast

    No inference round-trip — rules run locally.
