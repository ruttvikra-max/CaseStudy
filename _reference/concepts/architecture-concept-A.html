Concept A · Analogy-led · “Two rooms”
The architecture constraint

Figma splits every plugin into two rooms that can’t see each other.

One room can read your design file but has no screen. The other can draw the interface but is blind to the file. The only way between them is a note passed through the wall — so that’s exactly how the engine was designed.

The engine room

Plugin sandbox · code.ts
  • Can: Reads every layer, colour, token and component in your file
  • Cannot: Has no screen — it can’t show you anything
  • Cannot: No internet — network access is switched off, so nothing leaves

Its job: walk the file, find drift, calculate the score.

One note
ANALYSIS_COMPLETE

The display room

UI iframe · React
  • Can: Draws a full interface — scores, charts, buttons
  • Cannot: Can’t open your file — it only knows what the note says
  • Cannot: Can’t reach in and change a single layer

Its job: show the score, the pillars and every issue, screen by screen.

Think of a bank. The vault holds everything valuable but has no counter. The teller’s window serves customers but can’t open the vault. A slot in the wall passes one envelope at a time — and the valuables never cross it.

Why that shaped the design
01

Private by construction

Your design data stays in the engine room. Only the findings cross the wall — and nothing goes online.

02

One clear contract

Engine and interface agree on a single typed message, so each can be built, tested and changed on its own.

03

Same file, same score

The engine has no screen to worry about — it only measures. That keeps the scoring deterministic.

For engineers: the actual constraint
code.ts — main thread
Runs in Figma’s sandbox: modern JS plus the figma.* scene API (nodes, variables, styles). No DOM, window, XHR or setTimeout.
ui.html — iframe via figma.showUI()
Full browser APIs, so React renders here. No access to the Figma scene.
The bridge
figma.ui.postMessage() ⇄ parent.postMessage({ pluginMessage }, '*') — structured-clone messages, nothing shared.
Network
networkAccess.allowedDomains: ["none"] in the manifest — Figma blocks every outbound request.
