The architecture constraint

The part that reads your file can’t draw. The part that draws can’t read.

Figma splits every plugin in two. Your file stays with one half; one message crosses back.

  1. 1

    Panel: draws, can’t see the file UI iframe

  2. 2

    Engine: reads, can’t draw, offline* code.ts

  3. 3

    Wall: neither half does the whole job

  4. 4

    Slot: ANALYSIS_COMPLETE findings only

*“Offline” assumes the manifest’s allowedDomains blocks the network; not yet verified. Tap a number to light it up.
