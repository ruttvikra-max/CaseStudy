Decision 02

Deterministic — not AI-first.

“The most dangerous thing you can add to a governance tool is uncertainty. The same file should always produce the same score.”

Every design tool today reaches for an LLM. But a governance metric that changes without the file changing isn’t a metric — it’s a guess. So the measurement core stays deterministic. That single constraint earns four properties for free:

  1. 01

    Reproducible

    Same file, same score — every run, every machine. A team can track a number over time and trust that it moved because the file moved.

  2. 02

    Private

    Nothing is sent to a model to be read. The rules run inside Figma’s sandbox, so proprietary design data never leaves your machine.

  3. 03

    Offline

    No API, no model endpoint, no connection required. The audit works wherever Figma works.

  4. 04

    Fast

    A scan waits on nothing. No inference queue, no network round-trip — rules run locally against the layer tree.
